## 一句话

圆头萌系 3D、暖光小店、家具精致、粉薄荷绿奶白——像把《开间小店》的咖啡厅换成烘焙店；外景是可逛的小街区。

## 关键词

| 要 | 不要 |
|----|------|
| Q 版大头、短四肢 | 写实比例 |
| 软圆边家具、玻璃柜细节 | 灰盒硬棱 |
| 暖窗光 + 淡阴影 | 午夜暗场 / 重对比 |
| 粉樱 `#F4A7B9` · 薄荷 `#8FCFC0` · 奶白 `#FFF7F0` · 木色 `#D2A679` | 紫霓虹、土陶红套路、剪纸扁平 |
| 店员围裙可读、客人配色区分 | 像素块、黏土脏脏感 |

## 角色规格

- **店员**：头身约 1:1.8～2；大头圆脸；围裙 + 小帽或发带；待机轻晃  
- **客人**：同比例，现有 **6** 套（粉 / 蓝 / 黄 / 薄荷 / 牛仔 / 小孩）  
- **表情**：开心/等餐靠气泡 + 耐心条，暂不做复杂脸部动画
