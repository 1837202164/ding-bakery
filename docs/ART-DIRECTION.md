# 《叮——》美术锁定：韩系 Q 版小店

**参照**：手游《开间小店》（韩系卡通 Q 版咖啡厅经营）  
**不是**：抄模型/贴图；只对齐气质与制作规格。

锁定 moodboard：`art/direction/locked-qshop.png`

## 一句话

圆头萌系 3D、暖光小店、家具精致、粉薄荷绿奶白——像把《开间小店》的咖啡厅换成烘焙店。

## 关键词

| 要 | 不要 |
|----|------|
| Q 版大头、短四肢 | 写实比例 |
| 软圆边家具、玻璃柜细节 | 灰盒硬棱 |
| 暖窗光 + 淡阴影 | 午夜暗场 / 重对比 |
| 粉樱 `#F4A7B9` · 薄荷 `#8FCFC0` · 奶白 `#FFF7F0` · 木色 `#D2A679` | 紫霓虹、土陶红套路、剪纸扁平 |
| 店员围裙可读、客人配色区分 | 像素块、黏土脏脏感 |

## 角色规格

- **店员**：头身约 1:1.8～2；大头圆脸；围裙 + 小帽或发带；待机轻晃  
- **客人**：同比例，2～3 套服装色（粉/蓝/黄）  
- **表情**：开心/等餐靠气泡 + 耐心条，暂不做复杂脸部动画  

## 场景规格

### A. 小开放街区（外景，类开放世界）

不是无边大地图，而是 **一块可连续走动的小镇**（微信包体友好）：

| 分区 | 作用 |
|------|------|
| 中央广场 | 枢纽、喷泉、汇合点 |
| 商业街 | 通往烘焙店的主路 |
| 烘焙店外立面 | 进店交互点 |
| 小公园 | 休闲/氛围，可放偶遇客人 |

概念：`art/scene/openworld/`  
相机：仍可用 **固定高机位 / 轻跟随**，空间感靠分区铺开，不做自由飞行相机。

### B. 店内（进店后）

- 木地板浅纹、后墙奶白 + 窗光板  
- 柜台木色圆角、展柜玻璃、烤箱暖光  
- 桌椅成套；解锁：窗台花 / 地毯 / 灯  
- 母版：`art/scene/shop-interior.png`  
- 六视面：`views/table-chair/` · `cabinet/` · `window-wall/`
