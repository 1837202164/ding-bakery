# 《叮——》微信小游戏发布指南（M4）

本机需安装：**Cocos Creator 3.8.x**、**微信开发者工具**。

## 1. 打开工程

1. 用 Cocos Dashboard / Creator 打开 `ding/`
2. 新建空场景，根节点挂 `GameRoot`
3. 设为启动场景并保存为 `assets/scenes/Main.scene`

## 2. 构建设置（微信小游戏）

菜单：**项目 → 构建发布**

| 项 | 建议 |
|----|------|
| 发布平台 | 微信小游戏 |
| 初始场景 | `Main` |
| 资源服务器 | 可先空（本地包） |
| 设备方向 | **横屏**（Landscape） |
| 设计分辨率 | 1280 × 720，Fit Width |
| AppID | 填你的小游戏 AppID（测试可用游客/测试号） |

构建目录默认：`ding/build/wechatgame/`

## 3. 用微信开发者工具打开

1. 打开微信开发者工具 → 导入项目
2. 目录选 `ding/build/wechatgame`
3. AppID 与构建时一致
4. 详情 → 本地设置：勾选「不校验合法域名」（开发期）

构建产物旁可参考本仓库 `build-templates/wechatgame/` 中的说明字段。

## 4. 触控说明（无键盘）

微信里没有 `E` / `1/2/3` / 空格。请使用场景内 **TouchHud**：

| 按钮 | 作用 |
|------|------|
| 座位1/2/3 | 准备阶段摆座 |
| 开业 / 下一步 / 再来一天 | 主操作（随阶段变化） |
| 互动 | 接单 / 打开制作 / 上餐 |
| 取消 | 取消当前制作 |
| 窗台花 / 地毯 / 灯笼 | 准备或打烊时用小费购买装扮 |

本地进度键：`ding-save-v1`（最佳星、天数、小费罐、已购装扮）。

点地板移动仍然可用（触摸 = 点击）。

## 5. 包体与性能清单

- [ ] 灰盒阶段先过审玩法；正式美术用压缩纹理（ASTC/ETC）
- [ ] 避免过大音频；SFX 用短 WebAudio / 小音效
- [ ] 主包尽量 < 4MB；超出部分放远程分包
- [ ] 真机预览：低端安卓看帧率与发热
- [ ] 关闭调试日志（正式包不要刷 `console.log`）
- [ ] 确认横屏锁定与安全区（刘海）不挡 HUD

## 6. 常见问题

**构建报错找不到场景**  
先在编辑器保存并设置启动场景。

**触摸点地没反应**  
确认有物理射线或平面求交；`PlayerController` 已支持无碰撞时的 y=0 平面回退。

**键盘在开发者工具能用、真机不能**  
属正常；以 TouchHud 为准。

**要接开放数据域 / 排行榜**  
完整版再做；垂直切片不包含。
