治愈烘焙小店垂直切片。**逻辑已封板**，下一步按仓库根目录 `docs/ART.md` 换美术。

## 打开

1. Cocos Creator **3.8.x** 打开本目录  
2. 空场景根节点挂 `GameRoot`  
3. 预览；无 Creator 时先跑同级 `preview/`
